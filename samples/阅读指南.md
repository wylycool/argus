# 把注意力，留给文字。

欢迎来到 **Argus**。这里是一处安静的阅读空间，让 Markdown 回到它最好的样子：清晰、自然、专注。

> 阅读是一种缓慢的对话。不必急着抵达结尾，先享受眼前这一段。

## 从一份文档开始

点击左上角的「文件 → 打开文档」，或者按下 `⌘ O`，选择你的 Markdown 文件。也可以把文件直接拖进窗口，或在 Finder 中使用「打开方式 → Argus」。

左侧的**已打开文件**只显示你主动打开的文档。点击当前文件下方的**文档大纲**，即可查看当前文档的章节并点击跳转；点击返回箭头回到文件列表。文件名右侧的 × 仅关闭文档，不会删除原文件。最近阅读收在「文件 → 最近阅读」中。

### 一边编辑，一边看效果

点击右上角「编辑」，再开启「预览」，即可在左侧输入 Markdown、右侧查看效果。拖动中间分隔条调整宽度，双击恢复对半；关闭「联动滚动」可以分别查看两侧。窗口较窄时，用「编辑 / 预览」标签切换，输入与撤销记录仍会保留。

预览直接展示当前输入，不需要先保存。自动保存继续工作，点「保存」回到阅读。

### 为长文而设计

- 适合中英文混排的字体与宽松行距
- 限制正文行长，让目光轻松回到下一行
- 记住文档、主题和阅读位置，下次接着读
- 源码仅供查看，不会意外改动你的文件

## 文字的不同表达

用 **粗体**强调重点，用 *斜体*放轻语气，也可以使用 ~~删除线~~ 或 **粗体与 *斜体* 的组合**。行内代码如 `const reader = 'Argus'` 会保持自己的节奏。

1. 打开一份你想读的文档
2. 选择舒服的浅色或深色主题
3. 隐藏侧栏，进入更专注的阅读
   - 使用 `⌘ \` 随时切换导航
   - 使用 `⌘ ⇧ M` 切换源码与阅读视图

### 让计划清晰可见

- [x] 留出完整的阅读时间
- [x] 整理今天的笔记
- [ ] 读完那篇一直收藏的文章

任务列表会如实展示文件中的状态。Argus 是阅读器，点击不会修改原文件。

## 代码，也值得好好阅读

代码块会根据语言自动高亮，右上角可以一键复制。

```typescript
interface ReadingSession {
  document: string;
  progress: number;
}

function continueReading(session: ReadingSession) {
  const { document, progress } = session;
  return `继续阅读 ${document} · ${progress}%`;
}
```

```python
from pathlib import Path

notes = Path("我的笔记")
for document in notes.glob("*.md"):
    print(document.name)
```

## 把信息放在一起

| 快捷键 | 操作 | 说明 |
| :--- | :--- | :--- |
| `⌘ O` | 打开文档 | 系统文件选择器 |
| `⌘ R` | 重新读取 | 读取外部修改后的内容 |
| `⌘ ⇧ M` | 切换视图 | 阅读 / 只读源码 |
| `⌘ ⇧ L` | 切换主题 | 浅色 / 深色 |
| `⌘ \` | 切换导航 | 留出更大的阅读空间 |
