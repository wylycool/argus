# Argus 使用指南

适用于 0.10.0。下载和安装见[项目主页](../../README.md)。

## 文件与保存

- 支持 UTF-8 的 `.md`、`.markdown`、`.mdown`、`.mkd`，扩展名大小写均可。
- 单文档上限 16 MB。记录最近 12 篇文档，保留最多 100 篇文档的阅读位置。
- 文件列表只记录主动打开的文档，不扫描同目录。打开列表、当前文件和阅读位置随应用恢复；关闭文档不删除文件，也不清除最近阅读。
- 图片授权最多 1,000 张；相对路径图片和本地 Markdown 链接按当前文档位置解析。
- 单张本地图片上限 32 MB。图片加载失败时保留替代文字，不影响正文阅读。
- 关闭窗口保留应用；从 Dock 再次打开会恢复窗口。`⌘ Q` 完全退出。
- 只提供 Markdown 文本编辑，不做富文本、云同步或插件系统。暂不实现独立数学公式；使用系统打印面板另存PDF，并持续监测当前文件变化。
- 保存失败会保留编辑内容并阻止切换/关闭/退出；外部修改产生冲突后，提供重试、另存副本和明确确认后的重新读取。
- 未保存草稿备份位于 `~/Library/Application Support/app.argus.reader/drafts/`。重新打开文件后可恢复或放弃草稿。备份通常在输入停顿200ms或连续输入1s时触发；突然断电/强制终止时仍可能损失最近一小段尚未备份的输入。
- 正常保存前校验内容版本，并在原子替换前再次检查。文件被移走、改成只读或被外部修改时不会静默覆盖。
- 当前 DMG 使用本机临时签名，未进行 Apple Developer ID 签名与公证。跨机器分发时，macOS 可能提示无法验证开发者；首次打开可按 macOS 的“隐私与安全性”提示确认来源；请从本仓库 Releases 下载并校验 SHA-256。

快捷键：`⌘ E` 编辑/保存并返回阅读，`⌘ S`立即保存，`⌘ O` 打开，`⌘ ⇧ S`另存副本，`⌘ ⌥ ←`返回上一处，`⌘ R` 重新读取，`⌘ ⇧ M` 切换视图，`⌘ ⇧ L` 切换主题，`⌘ \` 切换导航。

## 边编辑边预览（0.10.0）

打开文档仍默认查看，点击右上“编辑”，再点“预览”即可左侧编辑、右侧显示效果。预览读取当前输入，与保存成功与否无关；自动保存继续工作，点击“保存”回到阅读。

- 拖动中间分隔条调整宽度；双击恢复对半，也可聚焦分隔条后按左右箭头调整。预览开关、比例和联动设置随本机保存。
- “联动滚动”按源码段落对应位置双向滚动。关闭后，两侧可分别阅读。图像、表格、代码和Mermaid沿用阅读渲染样式。
- 可用区域不足780px时切换为“编辑/预览”标签，不把两栏挤在一起。查找、插入图片和大纲定位会按需回到编辑页；开关与窗口变化保留编辑器和撤销记录。
- 普通输入短暂停顿约180ms更新预览，持续输入最多约700ms更新一次；超过100万字符的长文放宽至500ms/2秒。Mermaid在预览内容稳定约450ms后绘制，错误保留源码并可继续修改。
- 新输入的本地图片引用先走原有系统授权；网页/图片放大、文内锚点和Markdown文档链接沿用已有操作与保存保护。

开发者可运行 `npm run dev` 后访问 `http://127.0.0.1:1420/src/editor/preview/index.html`，使用演示文档体验预览；安装版请从 [Releases](https://github.com/wylycool/argus/releases/latest) 下载。

## Mermaid 图表

使用标准 `mermaid` 围栏代码块即可在阅读视图绘制。已实测中文流程图和时序图。点击图形或“放大”可按100%查看，并可缩放、滚动、适应窗口；按Esc关闭。下方“查看源码”可展开原始内容，解析出错时会自动展开并说明原因。

单篇自动绘制最多50张图，单图最多100,000字符和500条边；超限时保留源码。使用严格模式与SVG清理，不执行图表回调或嵌入HTML。普通文档不会启动Mermaid引擎。

默认图表会使用当前主题的低饱和配色、矩形微圆角、判断菱形细虚线和圆角连线标签。源码中的 classDef、style、linkStyle、YAML 配置或 init 指令优先，存在这些配置时不叠加默认装饰。安全相关配置仍受严格模式限制。

## 八套主题

暖白保持纯色纸面；暖白磨砂独立提供40%细颗粒纹理。淡紫使用340px渐变范围与30%浓度；雾蓝保持白色正文和局部淡蓝雾面；石墨使用中性炭灰夜读配色；晨光采用预览定稿的局部柔光，并在初版上降低8%强度。正式应用与HTML预览复用同一份主题CSS及图表色板，未单独放大纹理或渐变。

主题选择会记住。⌘ ⇧ L在上次浅色主题与上次深色主题（深绿或石墨）之间切换。预览调节滑块只属于开发预览页面，正式应用使用定稿值。

## 阅读效率与历史版本

- `⌘ F`查找当前文档，支持阅读、只读源码及编辑器。Enter/Shift Enter跳转，Esc关闭。阅读查找最多显示1,000个匹配，超出显示“+”；不包含折叠源码、图表SVG和工具按钮。
- 右上“外观设置”按钮打开主题与排版面板，切到“排版”调整字号14–26px、行距1.5–2.4、宽度560–1040px，选择随本机保存。`⌘ +`/`⌘ -`调字号，`⌘ 0`恢复默认。编辑器字号保持原值。
- “文件→历史版本”或`⌘ ⇧ H`查看本地历史。首次修改写盘前保存原文，持续编辑每5分钟可生成检查点；每篇最多20个，全局128MB/1,000条，最旧版本按需清理。历史从0.6.0首次编辑开始积累，不补造之前的版本。
- 恢复前会保留当前内容，并检查原文件有无外部修改；确认后才能恢复。原有BOM、换行与权限仍受保护。历史数据位于`~/Library/Application Support/app.argus.reader/history/`，不写进文档目录、不上传。
- 切回Argus时检查文件变化。阅读时可选择读取最新内容；编辑时暂停自动保存并保留输入，通过另存副本或重新读取处理。原文件丢失时保留当前显示，不静默清空。
- 历史备份失败会阻止本次覆盖，保留编辑内容供重试或另存。历史有容量上限，不等于永久版本库。

## 工作区操作

- 批量打开会去重，将全部成功项加入列表，并显示最后一篇成功文档。个别失败会列出路径与原因；不扫描同目录，不缓存所有文档全文。
- 左上“文件 → 另存副本”或原生“文件 → 另存为副本…”在阅读、编辑时均可使用。阅读保存当前源码，编辑保存当前输入。成功后切换到副本；取消或失败保留当前内容，同名文件不会静默覆盖。编辑期间此前的自动保存可能已更新原文件。
- 顶部返回箭头或`⌘ ⌥ ←`逐次返回之前文档、视图和滚动位置，最多保留本次运行的50处位置。返回失败保留当前文档与记录。
- 点击普通图片或选中后按Enter/空格可放大，支持适应窗口、1:1、10%–400%缩放和滚动；Esc关闭，正文位置不变。加载失败提供重试。
- 在文件列表右键，或聚焦文件后按Shift F10，可在Finder中显示、复制绝对路径、关闭其他文档。只移除列表，不删除文件。
- 大纲标题左侧箭头折叠子章节，标题本身跳转。当前子章折叠时标记其可见父章；操作大纲期间暂停自动定位，切换文档不串用折叠状态。
- 编辑前检查文件权限。只读时可以继续阅读，或另存为可写副本后直接编辑；恢复草稿时副本使用草稿内容。实际保存仍校验权限和磁盘版本。

## 新建、图片、PDF与文档管理

- `⌘ N`或“文件→新建文档”直接打开空白编辑器。未命名文档自动保存在本机；`⌘ S`首次选择文件位置后继续编辑，工具栏“保存”选择位置后回阅读。取消或失败保留输入。关闭未命名文档只移除列表，可以从`⌘ P`搜索本机未命名草稿；退出重启会恢复当前草稿。草稿文件位于应用数据目录的untitled/，不会上传。
- 编辑时点击图片按钮、“文件→插入图片”，或直接粘贴截图。单张粘贴上限8MB，选择原文件上限32MB；支持PNG/JPEG/GIF/WebP/BMP。写入文档旁assets/，按内容去重并插入相对链接。未命名文档先选择保存位置；失败保留原输入。撤销会撤回Markdown引用，保留图片文件以免破坏其他引用。
- `⌘ ⇧ P`或“文件→打印 / 另存为PDF…”打开macOS系统打印面板，在PDF菜单选择存储为PDF。打印当前内容，自动准备白底Markdown、代码、图片及浅色Mermaid，隐藏软件界面，不改变阅读主题。单次最多50图，图片未加载完成会提示重试。
- `⌘ P`打开快速切换，搜索已打开、最近和本机未命名草稿；方向键选择、Enter打开、Esc关闭，同名文件显示目录。切换仍先处理当前保存与冲突。
- 原生使用单个后台监测任务，每750ms检查当前文件元信息，变化后才读取版本；前台持续停留也能提示外部改动。编辑时保留输入、暂停自动保存，不能静默覆盖。
- 历史版本默认显示“历史→当前”差异，可切换只读源码。“管理历史”显示本文与全部占用，删除所选版本或清理本文历史均需确认；不改当前Markdown。差异对比限制合计100万字符/400ms/2500次修改，超过限制回退源码；原历史容量仍为每篇20版、全局128MB。

## 跨目录副本与内容搜索（0.9.0）

### 另存副本携带本地图片

使用`⌘ ⇧ S`或“文件→另存为副本”。保存到不同目录时，实际引用的本地图片会复制到目标旁的`副本名.assets-随机标识/`，按内容命名，避免不同目录中的同名图片互相覆盖。行内、引用式及HTML图片都支持；代码示例和注释不当作图片引用。Markdown其余部分保持原样。分享副本时要同时保留这个资源目录。

其他本地文档链接会调整为在当前保存位置继续指向原目标，不递归复制其他文档；本页链接指向新副本。网页图片仍保留原网址。同目录副本复用已有图片，首次保存未命名文档按选择的位置解释相对路径。原文权限、已有目标不覆盖和编辑保存保护仍生效；搬运图片时遇到缺失、权限或空间不足会报错并保留当前输入，未发布的资源目录会清理。

单篇16 MB，本地引用最多4000个、图片最多1000张，单张32 MB、合计128 MB。资源解析在独立工作线程执行，15秒超时会中止分析，保留当前文档。

### 搜索已打开文档的内容

`⌘ ⇧ F`、“编辑→搜索已打开文档”，或左上“文件 → 搜索文档内容”。只搜索当前“已打开文件”列表中的本地文档，不扫描目录，不自动加入最近阅读中的其他文件。当前编辑缓冲区会优先使用，包含尚未保存或因冲突暂停保存的输入。

输入普通关键词匹配内容和代码，默认忽略大小写，不把输入当作正则表达式。上下键选择，Enter或点击定位，Esc关闭。阅读时定位所在段落/代码块并短暂标记；编辑时精确选中命中文字。原始HTML缺少稳定渲染行时切到源码定位。切换文件沿用保存保护，失败则留在原编辑器；目标在搜索后发生变化会打开最新内容并提醒重新搜索。

每篇最多25处、总计500处；单次最多500篇、合计读取128 MB。无法读取的文件有明细，上限会提示。查询有去抖、取消和串行执行，不持久化全文索引。

运行验证：`npm run check`、`npm test`、`cargo test --manifest-path src-tauri/Cargo.toml`。开发环境与验证方式见[贡献指南](../../CONTRIBUTING.md)。
